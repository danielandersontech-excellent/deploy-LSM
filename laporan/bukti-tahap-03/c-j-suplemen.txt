## Klarifikasi urutan temuan i2 (dibaca bersama c-j-container.txt)
- Skrip utama: berkas dibuat SETELAH container app menyala -> curl /unggahan/uji-volume.txt = 404.
- Suplemen: container app sudah DIGANTI (down/up) setelah berkas ada -> 200; restart lagi -> tetap 200.
- Kesimpulan: Next.js produksi mendaftar isi public/ saat server MULAI; berkas yang ditambah saat
  server berjalan (= setiap unggahan) tidak dilayani sampai restart. Unggahan Tahap 5/6 harus
  dilayani route handler sendiri dari UPLOAD_DIR (bukan mengandalkan public/). TEMUAN, bukan cacat volume.
